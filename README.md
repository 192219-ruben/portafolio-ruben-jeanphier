# Portafolio Personal

## Descripción
Portafolio personal desarrollado como examen práctico de la asignatura
Ingeniería de Software I, aplicando control de versiones con Git y GitHub
y un flujo de trabajo basado en ramas.

## Tecnologías Utilizadas
- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Estructura de Ramas Utilizada
- master  
  Contiene la estructura base del proyecto (archivos y carpetas iniciales).

- develop  
  Rama de integración donde se consolidan las funcionalidades del proyecto.

- feature/JP-add-header  
  Implementación del header y menú de navegación.

- feature/JP-add-inicio  
  Implementación de la sección Inicio del portafolio.
